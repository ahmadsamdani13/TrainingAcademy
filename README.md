# Training Academy Website

## Project Description

Training Academy is a website made using HTML5 and CSS. It has three pages to provide course information and a student registration form.

## Website Pages

- index.html: This is the home page. It introduces the academy and lists four courses. It uses inline CSS.
- information.html: This page contains course details, a fee table, audio, and video. It uses embedded CSS.
- registration.html: This page contains a registration form with different input fields, radio buttons, checkboxes, a dropdown, and a text area. It uses external CSS from style.css.

## CSS Selectors

CSS selectors are used to select HTML elements for styling. The body selector is an element selector. The #registration-form selector is an ID selector. The .notice selector is a class selector. The input[type="email"] selector is an attribute selector.

In the declaration color: navy;, color is the property and navy is the value.

## Types of CSS

Inline CSS is written inside an HTML element using the style attribute. Embedded CSS is written inside the style tag in the head section. External CSS is written in a separate CSS file and linked to an HTML page.

## CSS History and Browser Support

CSS1 introduced basic styling. CSS2 and CSS 2.1 added more styling and layout features. Modern CSS has different modules for layouts, colors, and other features.

I will test the website in Google Chrome and Microsoft Edge to check the page layout, form validation, and media playback.

## HTML Elements

Semantic elements such as header, nav, main, section, and footer describe the purpose of content. Non-semantic elements such as div and span do not describe the meaning of their content by themselves.
